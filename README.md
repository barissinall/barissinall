### barissinall

I build creative tools with Claude Code: GPU-rendered brand visuals, design pipelines and skills that turn a rough idea into something you'd actually post.

## Featured

### [Shader Brand Kit](https://github.com/barissinall/shader-brand-kit)
One logo in, a premium brand kit out: liquid chrome, gold, thick glass and silk-gradient posts, stories and reels, rendered on your own GPU in seconds. Works as a Claude Code skill and plugin, and ships with an anti-slop review so the results don't look AI-generated.

[![Shader Brand Kit](https://raw.githubusercontent.com/barissinall/shader-brand-kit/main/examples/hero.jpg)](https://github.com/barissinall/shader-brand-kit)

```bash
claude plugin marketplace add barissinall/shader-brand-kit
claude plugin install shader-brand-kit@barissinall-plugins
```
